Orgkeep ships as container images, published on GitHub Container Registry. Nothing to build, only Docker.

Image What it is
orgkeep/orgkeep-core White label core (REST API only) View on GHCR →
orgkeep/orgkeep White label core (REST API + frontend) View on GHCR →
orgkeep/orgkeep-keycloak Keycloak + Orgkeep theme View on GHCR →

Images are tagged by release (for example :0.1.0) as well as :latest. Pin a version in production — Orgkeep is still 0.x, with no upgrade path between versions yet.

Try the demo stack

Keycloak, PostgreSQL, Orgkeep, Mailpit and example APIs, with demo organisations, accounts and catalogs already set up. 

git clone https://github.com/orgkeep/orgkeep-examples.git
cd orgkeep-examples/docker-compose
docker compose up -d --build

Then open http://localhost:8284 and log in as realm-owner (password password). The getting started guide walks through the demo accounts and the first screens to look at.

Orgkeep is an early preview: ready to be tried, not yet to run in production, with no upgrade path between 0.x versions and no service accounts yet. The README lists the known limitations, and your feedback is welcome in the issues.
